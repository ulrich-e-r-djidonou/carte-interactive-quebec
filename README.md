# carte-interactive-quebec

Systeme modulaire en Python pour generer et visualiser des cartes choroplethes interactives du Quebec selon differentes echelles geographiques : regions administratives, MRC et municipalites (villes). Permet d'associer dynamiquement des variables socio-economiques, demographiques ou sectorielles personnalisees et d'exporter des visualisations interactives autonomes en HTML ou de les piloter via une interface web.

## Stack technique

- Python 3.13
- Folium / Leaflet (cartes interactives autonomes, infobulles, echelles de couleurs, controles de couches)
- Plotly (choroplethes rapides, cartes Mapbox/OSM et graphiques couples)
- Pandas (manipulation et appariement des donnees)
- Streamlit (tableau de bord applicatif interactif)
